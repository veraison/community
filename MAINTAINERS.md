# Veraison Maintainers

This is the directory of people with a maintainer or code-owner role in the Veraison project.
See [GOVERNANCE.md](./GOVERNANCE.md) for the process how maintainers are appointed.

Who maintains what is defined by the GitHub teams below, which are used in each repository's `CODEOWNERS` file:

| Team | Scope |
|------|-------|
| [veraison-org-maintainers](https://github.com/orgs/veraison/teams/veraison-org-maintainers) | Veraison org maintainers and code owners of all repositories |
| [go-cose-maintainers](https://github.com/orgs/veraison/teams/go-cose-maintainers) | Maintainers of the [go-cose](https://github.com/veraison/go-cose) repository |
| [ratsd-maintainers](https://github.com/orgs/veraison/teams/ratsd-maintainers) | Maintainers of the [ratsd](https://github.com/veraison/ratsd) repository |

Additional contributors for single repositories can be added to the respective `CODEOWNERS`.

Keep this in sync with the GitHub organizations.
